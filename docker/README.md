# Test scripts

The scripts and Dockerfiles here run camex's end-to-end tests in Docker
(`docker/test-e2e-all.sh`); they are not for running a server.

To run the camex server in Docker, use [deploy/compose.yaml](../deploy/compose.yaml)
([docs/install.md](../docs/install.md#docker)).
